# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Instead, use [GitHub's private vulnerability reporting](https://github.com/utsavg05/StickyEdges/security/advisories/new) and include:

- A description of the issue and its impact.
- Steps to reproduce it.
- Any proof of concept or suggested fix, if available.

We will acknowledge reports as soon as practical, investigate the issue, and coordinate a fix before public disclosure.
