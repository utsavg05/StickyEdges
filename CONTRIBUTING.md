# Contributing to Sticky Edges

Thanks for helping make Sticky Edges better. The project aims to remain lightweight, local-first, and focused on the experience of physical notes attached to a desktop edge.

## Getting started

1. Fork the repository and create a branch from `main`.
2. Install dependencies with `npm install`.
3. Start the app with `npm run dev`.
4. Make one focused change, then run `npm run build` before opening a pull request.

## Pull requests

- Explain what changed and why.
- Keep pull requests small and focused.
- Include screenshots or a short recording for visual or interaction changes.
- Do not add cloud services, accounts, telemetry, or unrelated productivity features without discussing them first.
- Preserve local persistence and Windows desktop behavior.

## Reporting bugs

Open an issue with:

- Windows version and display scaling level.
- Sticky Edges version.
- Clear reproduction steps.
- Expected and actual behavior.
- Screenshots or a short recording when useful.

## Feature ideas

Open an issue before implementing large changes. The best ideas strengthen the core desktop-edge interaction without turning Sticky Edges into a full productivity suite.
